# 🎵 JioSaavn-Style Music Player UI

A **music streaming website UI project** built with **HTML and CSS**.  
This project recreates the structure of a modern music streaming homepage, including trending songs, artist radios, language selection, navigation, footer sections, and a music queue.

> **Note:** This is a frontend/UI project created for learning and practice. It is not an official JioSaavn application or affiliated project.

## ✨ Features

- 🎧 Trending music section
- 👨‍🎤 Artist Radio section
- 🔎 Search bar UI
- 🌐 Music language selector
- ▶️ HTML5 audio player controls
- 📋 Music queue panel
- ❤️ Favorite/like UI elements
- 🔐 Login and Sign Up navigation UI
- 📱 Music categories and browsing links
- 🧭 Navigation header
- 📚 Multi-column footer
- 🖼️ Album artwork and artist images

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and audio elements |
| CSS3 | Layout, styling, transitions and UI |
| HTML5 Audio | Music playback controls |
| External Images | Album and artist artwork |

## 🚀 How to Run

### Option 1 — Open directly

1. Download or clone this repository.
2. Open `jio-raho.html` in a web browser.
3. The music player interface will load.

### Option 2 — Use VS Code

1. Open the project folder in **Visual Studio Code**.
2. Open `jio-raho.html`.
3. Use **Live Server** or open the file directly in your browser.

## 🎵 Music & Audio

The HTML contains examples of album artwork and audio-player elements. Some audio sources currently point to local Windows file paths such as:

```text
C:\Users\Administrator\Downloads\Gehra Hua.mp3
```

These paths only work on the computer where those files exist.

For a GitHub-hosted project, replace local audio paths with audio files included in the project or with properly licensed/authorized audio URLs.

## 🖼️ Images

The project uses album and artist artwork through image URLs and embedded image data.

If you publish this project publicly, make sure you have permission to use any copyrighted images, artwork, logos, or music.

## ⚠️ Current Limitations

This version is primarily a **static frontend prototype**.

- Search is currently UI-only.
- Login and Sign Up links are not connected to authentication.
- Navigation links are placeholders.
- The language selector does not dynamically change the content.
- The queue UI is currently static.
- Music files using local Windows paths will not work for other users.
- There is no backend or database.
- Responsive/mobile optimization can be improved.
